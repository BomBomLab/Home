## 小克桌宠安装方式 / How To Install Clawd Deskpet

如果你拿到的是打包好的 `.app` 或 `.zip`：

1. 解压后得到 `Clawd Deskpet.app`
2. 将它拖到 `Applications`
3. 第一次打开如果被 macOS 拦截，请右键应用后选择“打开”
4. 如果系统仍然拦截，可以前往“系统设置 -> 隐私与安全性”手动放行

If you received a packaged `.app` or `.zip`:

1. Unzip it to get `Clawd Deskpet.app`
2. Drag it into `Applications`
3. If macOS blocks the first launch, right-click the app and choose `Open`
4. If it is still blocked, allow it in `System Settings -> Privacy & Security`
