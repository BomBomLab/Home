## 小克桌宠安装方式 / How To Install Clawd Deskpet

如果你不擅长使用github，clone下载本项目到本地，双击打开“/BomBomLab-Home/apps/clawd-deskpet/dist/mac-arm64/Clawd Deskpet.app”即可。
第一次打开如果被 macOS 拦截，请右键应用后选择“打开”
如果系统仍然拦截，可以前往“系统设置 -> 隐私与安全性”手动放行
